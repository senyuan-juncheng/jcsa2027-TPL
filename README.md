# TensorProjection Layer: Taiwanese Mandarin speech-recognition example

This repository contains the code used for the Taiwanese Mandarin speech-recognition example in the JCSA manuscript on the TensorProjection Layer (TPL).

The experiment compares two neural-network models with the same output dimension after the dimension-reduction stage:

- **Baseline:** dimension reduction by max pooling.
- **TPL:** dimension reduction by the TensorProjection Layer.

The downstream BiGRU and output layers are otherwise shared in structure.

## Data

The example uses the **Taiwanese Mandarin** portion of the Mozilla Common Voice dataset. Only entries in `validated.tsv` are considered, and recordings longer than 5 seconds are removed during preprocessing.

For the analysis reported in the manuscript, the preprocessing pipeline retained **81,249 recordings**. The resulting input array has shape

```text
(81249, 1, 64, 626)
```

Raw Common Voice data are not included in this repository.

Place the data as follows:

```text
tensorprojection-layer-jcsa/
├── data/
│   ├── validated.tsv
│   └── clips/
├── npy/                  # generated by preprocessing; not tracked
├── results/              # generated by experiments; not tracked
└── python/
```

## Setup

Create a Python environment and install the required packages:

```bash
pip install -r requirements.txt
```

Package versions are intentionally not pinned here because an exact environment snapshot was not preserved with the original experiment code.

The Bopomofo conversion step uses `g2pW`. If its model files are downloaded locally into `python/G2PWModel/`, they are ignored by Git.

## Reproducing the preprocessing

Run the preprocessing notebooks in order from the `python/` directory:

```text
step1_preprocess.ipynb
step2_translate_to_bopomofo.ipynb
step3_build_syllable_vocab.ipynb
```

They produce the generated files under `../npy/`:

```text
npy/
├── X.npy
├── meta.csv
└── vocab.json
```

The main preprocessing settings are:

- sampling rate: 16 kHz
- maximum recording length: 5 s
- FFT size: 400
- hop length: 128
- Mel bins: 64
- maximum time frames: 626

## Running one experiment

The model type and random seed can be supplied through environment variables. From the `python/` directory:

```bash
MODEL=baseline SEED=123 jupyter nbconvert \
  --execute --to notebook experiment.ipynb \
  --output /tmp/experiment_baseline_seed123.ipynb
```

or

```bash
MODEL=tpl SEED=123 jupyter nbconvert \
  --execute --to notebook experiment.ipynb \
  --output /tmp/experiment_tpl_seed123.ipynb
```

The main training settings in `experiment_config.py` are:

- train / validation / test split: 85% / 5% / 10%
- optimizer: AdamW
- learning rate: `1e-3`
- weight decay: `1e-4`
- batch size: 256
- maximum epochs: 100
- early-stopping patience: 5
- BiGRU hidden size: 256 per direction
- BiGRU layers: 2
- dropout: 0.2

Each run writes its outputs to

```text
results/<model>/seed_<seed>/
```

including the run configuration, training history, test metrics, and the best model state.

## Reproducing the 20 × 2 comparison

The manuscript comparison uses seeds 120--139 for both models. Run:

```bash
cd python
bash run_20x.sh
```

This executes 20 Baseline runs and 20 TPL runs.

After all runs finish, execute

```text
analyze_20x2_results.ipynb
```

to collect the test results and generate the three boxplots for CTC loss, syllable accuracy, and exact accuracy.

## Notes on evaluation

The main reported metrics are computed from the CTC-decoded Bopomofo syllable sequences:

- CTC loss
- syllable accuracy (`1 - SER`)
- exact accuracy

The code also contains an auxiliary Taiwan-pronunciation-equivalence evaluation. This is kept in the repository because it was part of the analysis code, but the manuscript's main comparison uses the strict metrics.
